Задание по треку «Сервис сокращения URL»

Добавьте в сервис функциональность аутентификации пользователя.
Сервис должен:
Выдавать пользователю симметрично подписанную куку, содержащую уникальный идентификатор 
пользователя, 
если такой куки не существует (надо хранить в storge куку) 
или она не проходит проверку подлинности. (надо валидировать куку ключом)

Иметь хендлер GET /api/user/urls, который сможет вернуть пользователю все когда-либо 
сокращённые им URL в формате:
[
    {
        "short_url": "http://...",
        "original_url": "http://..."
    },
    ...
] 

Если кука присутствует в запросе, но не содержит ID пользователя, 
хендлер должен возвращать HTTP-статус 401 Unauthorized. (надо провалидировать куку и проверить есть ли такой ID)

При отсутствии сокращённых пользователем URL хендлер должен отдавать HTTP-статус 204 No Content.

Получить куки запроса можно из поля (*http.Request).Cookie(), 
а установить — методом http.SetCookie().
